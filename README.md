# Soap2Soap

Soap-to-Soap: Video-to-Video generation powered by Gemini. Transform any video into stylized keyframes and video clips with consistent characters, clothing, and environments.

## Quick Start

### One-Click Generation (Keyframes + Video)

```bash
# From a video file (manually upload character faces)
./one_click_generate.sh your_video.mp4 disney

# From a video file (AI auto-generates character faces)
./one_click_generate.sh your_video.mp4 disney --auto-generate-face

# From a JSON script (skip video understanding step)
./one_click_generate.sh your_script.json disney --auto-generate-face
```

This will automatically:
1. Understand the video and generate a script (if input is a video)
2. Generate character sheets
3. Generate environment and costume reference images
4. Generate keyframe images and video clips for all shots
5. Concatenate all clips into a final video

### Available Styles

| Style | Description |
|-------|-------------|
| `realistic` | Photorealistic (default) |
| `disney` | Disney animation |
| `anime` | Anime |
| `japanese_anime` | Japanese manga |
| `clay` | Clay animation |
| `lego` | Lego |
| `family_guy` | Family Guy (American cartoon) |

### Regenerate Specific Keyframes

After the initial generation, you can interactively select and regenerate individual keyframes:

```bash
# Interactive mode - select which shots to regenerate
python regenerate_shots.py --script your_script.json --style disney

# Regenerate with backup of original images
python regenerate_shots.py --script your_script.json --style disney --backup

# Disable quality inspection
python regenerate_shots.py --script your_script.json --style disney --no-inspection
```

Interactive commands during regeneration:
- Enter numbers (e.g., `1,3,5`) to select specific shots
- Use ranges (e.g., `1-5`) for batch selection
- Type `all` to regenerate all shots
- Type `failed` to regenerate only failed/ungenerated shots

## Setup

### 1. Prerequisites

- **Python 3.8+**
- **ffmpeg** (required for video understanding and video concatenation)
  - macOS: `brew install ffmpeg`
  - Ubuntu: `sudo apt install ffmpeg`
  - Windows: Download from https://ffmpeg.org/download.html and add to PATH

### 2. Install Python Dependencies

```bash
pip install google-genai Pillow opencv-python scenedetect[opencv] openai-whisper
```

> **macOS (Homebrew Python):** If you get a `externally-managed-environment` error, add `--break-system-packages`:
> ```bash
> pip install --break-system-packages google-genai Pillow opencv-python scenedetect[opencv] openai-whisper
> ```

> **First run note:** Whisper will automatically download the `medium` model (~1.4 GB) on first use. Make sure you have enough disk space and a stable network connection.

| Package | Purpose |
|---------|---------|
| `google-genai` | Gemini API client (image/video generation, video understanding) |
| `Pillow` | Image processing |
| `opencv-python` | Video reading and frame extraction |
| `scenedetect[opencv]` | Video scene detection and splitting |
| `openai-whisper` | Speech-to-text transcription |

### 3. Configure Gemini API Key

Get your API key from [Google AI Studio](https://aistudio.google.com/apikey), then set it as an environment variable:

**macOS / Linux (add to `~/.bashrc` or `~/.zshrc`):**
```bash
export GENAI_API_KEY="your_api_key_here"
```

**Windows PowerShell:**
```powershell
$env:GENAI_API_KEY = "your_api_key_here"
```

**Windows CMD (persistent):**
```cmd
setx GENAI_API_KEY "your_api_key_here"
```

> Note: After `setx`, you need to restart the terminal for it to take effect.

### 4. Verify Setup

```bash
python -c "import google.genai; print('google-genai OK')"
python -c "from PIL import Image; print('Pillow OK')"
python -c "import cv2; print('opencv OK')"
ffmpeg -version
```

## Output

- **Keyframe images**: `shot_<id>.png`
- **Video clips**: `shots/shot_<id>_video.mp4`
- **Final video**: `final_output_<timestamp>.mp4`

## Example Output

The `output_reference/` folder contains a complete example generated from a short Titanic video clip processed in Disney style using manually uploaded character face references (from the `reference/` folder).

### Input
- **Source video**: `minitest_titanic.mp4` (a short Titanic clip)
- **Style**: `disney`
- **Face mode**: Manually uploaded faces from `reference/` (jack.png, rose.png, sailor.png, etc.)

### Generated Files in `output_reference/`

| File / Directory | Generated by Step | Description |
|------------------|-------------------|-------------|
| `disney_titannictest.json` | Step 1: Video Understanding | Parsed script with scene descriptions, camera angles, and character actions |
| `main_characters_1.png` | Step 2: Character Sheet | Montage image of main characters |
| `supporting_characters_1.png` | Step 2: Character Sheet | Montage image of supporting characters |
| `character_mapping.json` | Step 2: Character Sheet | Maps video characters to target face references |
| `character_position_mapping.json` | Step 2: Character Sheet | Records character positions in the montage images |
| `generated_faces/` | Step 2: Character Sheet | Cropped individual face images extracted from uploaded references |
| `reference_images/` | Step 3: Reference Generation | Environment and costume reference images per major scene |
| `memory_allocation.json` | Step 4: Memory Allocation | Stores visual DNA, character mappings, and narrative context for each shot |
| `shot1_grid.png` ~ `shot7_grid.png` | Step 4: Keyframe Generation | Grid preview of generated keyframe images |
| `shot_1_video.mp4` ~ `shot_7_video.mp4` | Step 4: Video Generation | Generated video clips for each shot |
